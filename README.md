## About Me

I'm a full-stack engineer who builds scalable web applications end to end. I work on modular, well-tested back-ends and fast, SEO-friendly front-ends.

- I design **RESTful APIs** with clean architecture, validation, and authentication
- I model and optimize **PostgreSQL** and **MongoDB** databases for performance
- I build **server-rendered and static** interfaces with Next.js and Tailwind CSS
- I deploy and maintain applications on **AWS** and Linux environments
- I enjoy working in teams through code reviews, clear Git workflows, and shipping reliably
